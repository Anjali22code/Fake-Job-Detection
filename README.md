# Fake Job Posting Detection

A Machine Learning based web application that detects whether a job posting is fake or legitimate.

## Project Overview

Fake job postings are increasing rapidly and can mislead job seekers. 
This project uses Machine Learning and Natural Language Processing to identify fraudulent job descriptions.

## Features

- Fake and legitimate job prediction
- Text-based job description analysis
- NLP preprocessing using TF-IDF
- Random Forest Classification
- Interactive Streamlit web interface

## Technologies Used

- Python
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Random Forest Classifier
- Streamlit

## Machine Learning Model

Algorithm Used:

- Random Forest Classifier

Text Feature Extraction:

- TF-IDF Vectorization

## Dataset

Dataset used:

Kaggle Fake Job Posting Dataset

## How It Works

1. User enters a job description.
2. The text is converted into numerical features using TF-IDF.
3. The trained Random Forest model analyzes the features.
4. The system predicts whether the job posting is fake or legitimate.
